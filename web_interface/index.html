🧠 Cochrane AI Screening Tool

AI-assisted systematic review screening for Cochrane reviews

🎯 Overview

This tool automates title/abstract screening for systematic reviews using AI. It compares AI decisions with human reviewers and calculates performance metrics.

🤖 AI Screening

Uses LLMs to screen studies based on PICO criteria.

📊 Comparison

Compares AI decisions with human reviewers (gold standard).

📈 Performance Metrics

Calculates accuracy, precision, recall, F1-score.

🎨 Visualization

Generates performance plots and reports.

🚀 Quick Start

  1. Install: pip install -e .
  2. Run screening: python scripts/run1_screening.py --review sample
  3. Compare results: python scripts/run2_comparison.py
  4. Evaluate performance: python scripts/run3_performance.py
